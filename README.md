# Number Guessing Game

A simple, interactive command-line number guessing game built using C. The program generates a random number within a specific range, and the player tries to guess it with helpful hints provided along the way.

## Features
* Random number generation for a unique experience every game.
* Real-time feedback (tells you if your guess is "Too High" or "Too Low").
* Score tracking based on the number of attempts taken.

## How to Run

### Prerequisites
You need a C compiler installed on your system (like GCC).

### Compilation
Open your terminal and run the following command:
```bash
gcc main.c -o guessing_game
```

### Execution
Run the compiled game:
```bash
./guessing_game
```

## How to Play
1. The computer will randomly pick a number between 1 and 100.
2. Input your guess when prompted.
3. Use the hints to adjust your next guess
